# Exercise 1 — Fuzzy Logic

### What was implemented

Inputs:

- Attendance
- Marks

Fuzzy labels:

- Low
- Medium
- High

Output:

- Poor
- Average
- Good
- Excellent

Example rules:

```text
IF attendance is LOW AND marks are LOW
THEN performance is POOR

IF attendance is MEDIUM AND marks are HIGH
THEN performance is GOOD

IF attendance is HIGH AND marks are HIGH
THEN performance is EXCELLENT
```

The program converts the numerical inputs into membership values, applies the rules, and calculates a final performance score and category.

# Exercise 2 — Constraint Satisfaction Problem

### Variables

```text
AI, DBMS, OS, NLP
```

### Possible time slots

```text
Mon/Tue/Wed × 9-10, 10-11, 11-12
```

### Constraints

1. No two courses can use the same time slot.
2. AI and DBMS must be on different days.
3. OS must occur before NLP.
4. AI cannot be on Monday 9-10.

The program searches possible assignments and keeps the first assignment that satisfies all constraints.

### Output

```text
 - TIMETABLE CSP
=================================================================
 AI    -> Mon 10-11
 DBMS  -> Tue 9-10
 OS    -> Mon 9-10
 NLP   -> Mon 11-12
 All slots unique: True
 AI and DBMS different days: True
 OS before NLP: True
 AI not Mon 9-10: True

=================================================================

```

### Observation

A timetable is accepted only when every constraint is satisfied. If even one constraint fails, that assignment is rejected.

# Conclusion

The experiment demonstrates two different AI techniques.

**Fuzzy Logic:** attendance and marks are represented with degrees of membership rather than only strict yes/no categories. The rules combine these values to produce a student-performance result.

**Constraint Satisfaction:** courses are variables, time slots are possible values, and constraints determine which combinations are allowed. The solver accepts only a timetable that satisfies all constraints.

Changing the fuzzy rule changes the interpretation of the same input. Changing a CSP constraint changes the set of valid solutions.

Therefore:

```text
Fuzzy Logic
Numerical input
     ↓
Membership values
     ↓
IF-THEN rules
     ↓
Performance output


CSP
Variables
     ↓
Possible values
     ↓
Constraints
     ↓
Valid timetable
```
