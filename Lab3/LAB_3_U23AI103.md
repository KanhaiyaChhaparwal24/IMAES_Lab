# Experiment 3 — Agent Architectures: The BDI Deliberation Cycle

## Aim

To implement a Belief–Desire–Intention (BDI) agent that updates its beliefs from a changing environment, chooses an intention from available goals, creates a shortest-path plan, and studies how the reconsideration interval `γ` affects performance.

## What we implemented

The program uses a simplified Tileworld on a **15 × 15 grid**. Beliefs are currently visible holes, desires are available holes, the intention is the selected hole, and the plan is the shortest path to it. The world can change while the agent acts.

## BDI cycle

```text
Perceive → update Beliefs → generate Options/Desires → select Intention
                         ↓
                    make a Plan
                         ↓
                   execute action
                         ↓
                 world changes
                         ↓
                  reconsider?
                         ↓
                      repeat
```

### Main events

- **COMMIT:** the agent chooses a hole and commits to it.
- **ACHIEVE:** the agent reaches and fills its intended hole.
- **DROP:** the intended hole disappears, so the intention is no longer achievable.
- **SWITCH:** on reconsideration, a different/better option replaces the current intention.

## Exercise 1 — Boldness against dynamism

The program evaluates `γ = 1, 2, 4, 8, bold` at world speeds `1, 2, 4, 8`. Each value is averaged over **25 random seeds**, with **600 agent steps per seed**.

```text
EXERCISE 1: GAMMA x WORLD SPEED SWEEP

γ	speed=1	speed=2	speed=4	speed=8
1	0.842	0.746	0.617	0.525
2	0.922	0.871	0.668	0.549
4	0.951	0.848	0.732	0.604
8	0.928	0.822	0.621	0.592
bold	0.938	0.828	0.637	0.639

Observation:
As world speed increases, old intentions become stale faster.
Therefore the best gamma tends to move toward smaller values.
Very small gamma spends more time deliberating; very large gamma risks
continuing toward holes that have disappeared. An intermediate gamma
balances thinking time against plan stability.
```

## Observations

### Effect of γ

- **γ = 1:** very cautious; it reconsideres frequently and reacts quickly to changes, but spends more time deliberating.
- **Large γ / bold:** spends less time reconsidering and executes plans for longer, which is useful when the world changes slowly. In a fast-changing world, the intention can become stale.
- **Intermediate γ:** balances deliberation and action.

### Effect of world speed

As world speed increases, holes appear/disappear faster. Therefore old intentions become stale faster and frequent reconsideration becomes more useful. In this particular implementation, the benchmark selected `γ = 1` at all tested speeds. This is an empirical result of this simplified simulator, not a universal rule.

### Why charge deliberation?

If thinking were free, reconsidering after every action would have no cost. Charging a time step makes the comparison meaningful because the world keeps changing while the agent deliberates.

### Single-minded vs open-minded

**Single-minded:** keeps its intention unless it is achieved or becomes unachievable.  
**Open-minded:** is willing to replace its intention when another option becomes better.

So single-minded commitment gives more persistence, while open-minded commitment gives more flexibility.

## Final conclusion

The experiment demonstrates the BDI deliberation cycle in a dynamic environment. The agent updates its **beliefs**, treats available holes as **desires/options**, commits to one as an **intention**, and follows a shortest-path **plan**. If the hole is filled, the intention is achieved. If the hole disappears, the intention is dropped. Reconsideration can also cause the agent to switch to another option.

The experiment shows the trade-off between **thinking and acting**. A very cautious agent spends more time deliberating, while a very bold agent can follow outdated intentions. In the implemented benchmark, `γ = 1` gave the highest mean effectiveness at all four tested world speeds, while overall effectiveness decreased as the world became faster.

> **In simple words: a BDI agent decides what it wants, commits to one goal, makes a plan, acts, and periodically checks whether that commitment is still sensible.**
