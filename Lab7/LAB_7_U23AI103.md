# Exercise 1 — Propositional Logic

## Problem

Represent:

```text
If it rains, then the road is wet.
```

Using:

```text
P = It rains
Q = The road is wet
```

The logical expression is:

```text
P → Q
```

The program generates all possible combinations of P and Q and evaluates the implication.

## Output

```text
======================================================================
1. PROPOSITIONAL LOGIC
======================================================================
Rule: If it rains, then the road is wet.  (P -> Q)

Rains(P) | Wet(Q) | P -> Q
------------------------------
False    | False  | True  
False    | True   | True  
True     | False  | False 
True     | True   | True  

Observation: implication is false only when it rains but the road is not wet.

======================================================================

```

## Observation

The implication is false only in this case:

```text
P = True
Q = False
```

In words:

> It rains, but the road is not wet.

For every other combination, `P → Q` is true.

# Exercise 3 — Probability of Events

The program uses a small dataset of 100 students:

| | Attended | Did not attend |
|---|---:|---:|
| Passed | 70 | 10 |
| Failed | 10 | 10 |

Therefore:

```text
Total = 100
Passed = 80
Attended = 80
Passed AND Attended = 70
```

The program calculates:

### Individual probability

```text
P(Passed) = 80/100 = 0.80

P(Attended) = 80/100 = 0.80
```

### Joint probability

```text
P(Passed AND Attended)
= 70/100
= 0.70
```

### Union probability

Using:

```text
P(A OR B) = P(A) + P(B) - P(A AND B)
```

we get:

```text
= 0.80 + 0.80 - 0.70
= 0.90
```

## Output

```text
 AND CONDITIONAL PROBABILITY
======================================================================
Dataset:
  Passed & attended       = 70
  Passed & not attended   = 10
  Failed & attended       = 10
  Failed & not attended   = 10

Individual probabilities:
  P(Passed)   = 80/100 = 0.80
  P(Attended) = 80/100 = 0.80

Joint probability:
  P(Passed AND Attended) = 70/100 = 0.70

Union probability:
  P(Passed OR Attended) = P(Passed)+P(Attended)-P(Both)
                        = 0.80+0.80-0.70
                        = 0.90

Conditional probabilities:
  P(Passed | Attended) = 70/80 = 0.88
  P(Attended | Passed) = 70/80 = 0.88

======================================================================

```

## Observation

The probability calculations show how individual events, their overlap, and their union are calculated from the same dataset.

# Exercise 4 — Conditional Probability

The experiment asks for conditional probabilities such as:

```text
P(A | B)
P(B | A)
```

For this dataset:

```text
P(Passed | Attended)
= P(Passed AND Attended) / P(Attended)
= 70/80
= 0.875
```

and:

```text
P(Attended | Passed)
= P(Passed AND Attended) / P(Passed)
= 70/80
= 0.875
```

So:

```text
P(Passed | Attended) = 0.875 = 87.5%

P(Attended | Passed) = 0.875 = 87.5%
```

The values happen to be equal here because the chosen dataset has the same number of passed students and attending students.

# Exercise 5 — Bayes' Theorem

The experiment uses a disease-diagnosis example.

Given:

```text
P(Disease) = 1%

P(Positive | Disease) = 95%

P(Positive | No Disease) = 5%
```

Bayes' theorem:

```text
P(Disease | Positive)
=
P(Positive | Disease) × P(Disease)
-----------------------------------
P(Positive)
```

First calculate:

```text
P(Positive)
=
P(Positive | Disease)P(Disease)
+
P(Positive | No Disease)P(No Disease)
```

Therefore:

```text
P(Positive)
=
(0.95)(0.01) + (0.05)(0.99)

= 0.0095 + 0.0495

= 0.059
```

Now:

```text
P(Disease | Positive)
=
(0.95)(0.01) / 0.059

≈ 0.1610
```

Therefore:

```text
P(Disease | Positive) ≈ 16.10%
```

## Output

```text
' THEOREM
======================================================================
P(Disease) = 0.01
P(Positive | Disease) = 0.95
P(Positive | No Disease) = 0.05

P(Positive) = (0.95)(0.01) + (0.05)(0.99)
            = 0.0590

P(Disease | Positive) = (0.95 × 0.01) / 0.0590
                      = 0.1610
                      = 16.10%

======================================================================

```

## Observation

A positive test does **not** mean that the person definitely has the disease.

The prior probability of disease was only 1%, and the false-positive rate was 5%. Bayes' theorem combines these values with the test evidence to obtain the updated probability.

# Conclusion

This experiment demonstrates two major types of reasoning used in AI.

### Logical reasoning

**Propositional Logic** works with statements that can be true or false and allows us to verify logical expressions using a truth table.

**First-Order Logic** allows us to represent objects, properties, and general rules. From:

```text
All humans are mortal
+
Socrates is a human
```

we can derive:

```text
Socrates is mortal
```

### Probabilistic reasoning

Probability allows us to reason when outcomes are uncertain.

We calculated:

- Individual probability
- Joint probability
- Union probability
- Conditional probability
- Bayesian posterior probability

Bayes' theorem showed how an initial belief can be updated after receiving new evidence.

Finally, the Matplotlib graph demonstrated how changing an input probability, specifically the prior probability, changes the Bayesian posterior.

Overall:

```text
Logical Reasoning
       ↓
Rules + Facts
       ↓
Logical conclusion


Probabilistic Reasoning
       ↓
Prior belief + Evidence
       ↓
Updated probability
```

The experiment therefore demonstrates how Python can be used to implement both deterministic logical reasoning and uncertainty-based probabilistic reasoning.
